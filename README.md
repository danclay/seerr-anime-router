# Seerr Anime Request Fixer/Router

This is a quickly vibecoded script to fix when you have a seperate anime Sonarr/Radarr instance and want requested media to be routed accordingly.

## Setup

1. Add your Sonarr/Radarr instances to Seerr
2. Disable autoapprove in Seerr. This script can auto approve for you after fixing things
